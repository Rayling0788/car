# PCB 底板设计指南

本文档面向嘉立创 EDA（立创 EDA）或 AD 画板，列出所有元件封装、板上连接、尺寸约束。

---

## 一、板子尺寸建议

- 外形：**80mm × 60mm**（根据底盘实际调整，四角 M3 安装孔）
- 安装孔：4 × Φ3.2mm，距边缘 3mm
- 层数：**双层板**（顶层信号+电源，底层 GND 覆铜）

## 三、原理图连接（网表）

### 3.1 电源部分

```
J1(BAT+) ── SW1(COM) 
SW1(NO) ── F1(IN)
F1(OUT) ──┬── 节点: VBAT_FUSED (7.4V)
           ├── U2(IN+)     MP1584① 输入
           ├── U3(IN+)     MP1584② 输入
           ├── U4(IN+)     MP1584③ 输入
           └── R1 ── D1(A) ── D1(K) ── GND    [绿LED 总电源指示]

J1(BAT-) ── GND（全板共地）

U2(OUT+) ── SW2(COM)
SW2(NO) ──┬── 节点: VCC_MCU (5V)
           ├── R2 ── D2(A) ── D2(K) ── GND    [红LED 主控路指示]
           ├── U1(5V引脚)   C8T6 供电
           ├── J7(VCC)      循迹 VCC
           ├── J8(VCC)      OLED VCC
           └── C3(+)── GND  [去耦]

U3(OUT+) ── SW3(COM)
SW3(NO) ──┬── 节点: VCC_AIM (5V)
           ├── R3 ── D3(A) ── D3(K) ── GND    [红LED 瞄准路指示]
           ├── J4(VCC)      舵机① VCC
           ├── J5(VCC)      舵机② VCC
           ├── J6(VCC) 脚2 空接 带电池版自供电
           ├── J9(VCC)      激光 VCC
           └── C4(+)── GND  [去耦]

U4(OUT+) ──┬── 节点: VCC_MOT (5V)
            ├── U5(VM)      TB6612 电机电源
            ├── U5(VCC)     TB6612 逻辑电源
            └── C5(+)── GND [去耦]

U2(OUT-) = U3(OUT-) = U4(OUT-) = GND
```

### 3.2 C8T6 → TB6612 电机驱动

```
U1(PA0)  ── U5(PWMA)     左电机 PWM
U1(PA1)  ── U5(PWMB)     右电机 PWM
U1(PA4)  ── U5(AIN1)     左电机方向
U1(PA5)  ── U5(AIN2)     左电机方向
U1(PB8)  ── U5(BIN1)     右电机方向
U1(PB9)  ── U5(BIN2)     右电机方向
U1(PB10) ── U5(STBY)     电机使能（代码默认拉低）

U5(AO1) ── J2(+)         左电机+
U5(AO2) ── J2(-)         左电机-
U5(BO1) ── J3(+)         右电机+
U5(BO2) ── J3(-)         右电机-
U5(GND) ── GND (多引脚全部接地)
```

### 3.3 C8T6 → 舵机

```
U1(PA6) ── J4(SIG)       舵机① 信号（水平）
U1(PA7) ── J5(SIG)       舵机② 信号（俯仰）
J4(GND) ── GND
J5(GND) ── GND
```

### 3.4 C8T6 → 激光

```
U1(PB0) ── J9(SIG)       激光信号（高=开）
J9(GND) ── GND
```

### 3.5 C8T6 → MaixCam（UART）

```
U1(PA9/TX)  ── J6(RX)    C8T6 发 → MaixCam 收
U1(PA10/RX) ── J6(TX)    C8T6 收 ← MaixCam 发
J6(GND) ── GND
```

### 3.6 C8T6 → 循迹模块

```
U1(PB3)  ── J7(OUT1)     最左
U1(PB4)  ── J7(OUT2)     左
U1(PB5)  ── J7(OUT3)     中
U1(PB12) ── J7(OUT4)     右
U1(PB13) ── J7(OUT5)     最右
J7(GND)  ── GND
```

### 3.7 C8T6 → OLED（I2C）

```
U1(PB6) ── J8(SCL)
U1(PB7) ── J8(SDA)
J8(GND) ── GND
```

### 3.8 SWD 下载口

```
U1(PA13) ── J10(SWDIO)
U1(PA14) ── J10(SWCLK)
J10(GND) ── GND
J10(3.3V) ── 可不接（仅供 ST-Link 检测用）
```

## 四、PCB 布局建议

```
┌────────────────────────────────────────────────────┐
│  [J1 电池]  [SW1] [F1]  [D1]                        │  ← 顶部：电源输入区
│                                                    │
│  [U2 MP1584①][SW2][D2]  [U3 MP1584②][SW3][D3]     │  ← 三路降压模块
│                          [U4 MP1584③]              │
│                                                    │
│  ┌──────────────────────────────┐                  │
│  │        U1 C8T6 插座           │                  │  ← 板中央：MCU
│  │   (2×20P 排母，跨中间)        │                  │
│  └──────────────────────────────┘                  │
│                                                    │
│  [U5 TB6612]    [J2左电机] [J3右电机]              │  ← 底部左：电机驱动
│                                                    │
│  [J4舵机①] [J5舵机②] [J9激光]                      │  ← 底部右：执行器接口
│                                                    │
│  [J6 MaixCam] [J7循迹] [J8 OLED] [J10 SWD]        │  ← 边缘：外接模块
│                                                    │
│  (M3)                                       (M3)  │
└────────────────────────────────────────────────────┘
```

## 五、走线规则

| 类型 | 线宽 | 过孔 | 备注 |
|------|------|------|------|
| 电池输入（7.4V） | ≥ 2mm / 79mil | Φ1.0mm | 走顶层，短粗 |
| 5V 电源线 | ≥ 1.5mm / 59mil | Φ0.8mm | 每路独立走，不共用细线 |
| GND | 底层整板覆铜 | 过孔 Φ0.3mm 打满 | 每个 IC/模块旁至少 2 个地过孔 |
| 信号线（GPIO/UART/I2C） | 0.25mm / 10mil | Φ0.3mm | 尽量走顶层 |
| PWM 线（舵机/电机） | 0.3mm / 12mil | — | 远离 UART/I2C，减少串扰 |

## 六、关键设计注意

1. **C8T6 插座方向**：在丝印标注 USB 口方向或 Pin1 标记，防止插反
2. **MP1584 模块方向**：丝印标注 IN/OUT 方向，三个模块方向一致
3. **TB6612 模块引脚顺序**：不同厂家引脚排列可能不同，买到后先确认再画封装
4. **去耦电容位置**：C3 靠近 U1(5V)，C4 靠近 J4/J5(VCC)，C5 靠近 U5(VCC)，C6 靠近 J7(VCC)，C7 靠近 J9(VCC)
5. **电机走线远离信号**：J2/J3 端子的走线与 UART/I2C 信号线保持 >5mm 间距
6. **SWD 接口放板边**：方便插拔 ST-Link
7. **丝印标注齐全**：每个排针旁标注引脚定义（GND/VCC/SIG 等），焊好后不用查文档

## 七、嘉立创 EDA 画板流程（简要）

1. 新建工程 → 原理图
2. 放元件（排母搜 `2.54mm Female Header`，KF301 搜 `KF301-5.08-2P`）
3. 按第三节连线，生成网表
4. 切换 PCB → 导入网表 → 布局（参考第四节）
5. 手动布线 + 铺铜
6. DRC 检查 → 无错误
7. 导出 Gerber → 下单（嘉立创 5 片包邮免费）

## 九、检查清单（画完板后核对）

- [ ] 所有网络已连接，DRC 无报错
- [ ] 电源线宽 ≥1.5mm，电池线 ≥2mm
- [ ] 底层 GND 覆铜完整，无孤岛
- [ ] C8T6 插座 Pin1 有丝印标记
- [ ] 所有排针接口旁有引脚定义丝印
- [ ] 安装孔 4×M3 位置与底盘对应
- [ ] 板子尺寸不超过底盘面积
- [ ] MP1584 输入输出方向正确
- [ ] TB6612 引脚顺序与实物一致
- [ ] SWD 口在板边缘，方便插拔
