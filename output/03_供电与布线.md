# 供电与布线

## 供电架构

```
电池 7.4V (2S 1500mAh)
  │
  ├── [总开关 SS-12F44] ── [PTC 2A] ──┬── MP1584① IN ── OUT 5V ── [开关1 + LED1] ──┬── C8T6 VIN
  │                                    │                                                ├── 循迹 VCC
  │                                    │                                                └── OLED VCC
  │                                    │
  │                                    ├── MP1584② IN ── OUT 5V ── [开关2 + LED2] ──┬── 舵机×2 VCC
  │                                    │                                                ├── MaixCam VCC
  │                                    │                                                └── 激光 VCC
  │                                    │
  │                                    └── MP1584③ IN ── OUT 5V ──────────────┬── TB6612 VM（电机功率）
  │                                                                              ├── TB6612 VCC（逻辑）
  │
  └── 所有 GND 共地 ──────────────────────────────────────────────────────────────
```

## 三路用途

| 路 | 开关 | 电压 | 负载 | 用途 |
|-----|------|------|------|------|
| ① | 开关1独立 | 5V | C8T6 + 循迹 + OLED | 主控及传感器，巡线时保持开启（5V 接 Blue Pill 板上 5V 引脚，经板载 LDO 降至 3.3V） |
| ② | 开关2独立 | 5V | 舵机×2 + MaixCam + 激光 | 瞄准模块，基本要求(1)巡线时断开 |
| ③ | 无独立开关 | 5V | TB6612 → 电机×2 | 电机功率，软件默认 STBY=0（PB10 拉低）防止意外转动 |

## 开关和 LED 接线

```
MP1584 OUT+ ─── 开关(中间脚) ─── 开关(边脚) ───┬── 负载 VCC
                                                │
                                                └── 1kΩ ─── LED(长脚) ─── LED(短脚) ─── GND
```

- 开关 SS-12F44：3脚，用 COM(中) + NO(边脚)
- LED 红色 3mm：长脚串 1k 电阻接开关输出，短脚接 GND
- 绿色 LED 接在总开关输出+保险后面，指示电池是否接入

## PCB 走线要求

- 电源线（5V / 电池输入）：**线宽 ≥ 1.5mm**（过 2A）
- 信号线：**线宽 0.25~0.3mm**
- 整板覆铜 GND，地过孔打满
- 每个模块旁边放 0.1μF 去耦电容，尽量靠近模块 VCC 引脚
- 电池入口：PTC 2A 自恢复保险，防短路

## 实测检查

上电前用万用表蜂鸣档：
1. VCC 与 GND 之间不通（不短路）
2. 各开关断开时对应路 0V
3. 各开关闭合后对应路 5V
4. LED 亮 = 对应路有电
