## 按模块分组

### 电机控制 → TB6612（7线）

| C8T6 | TB6612 | 说明 |
|------|--------|------|
| PA0 | PWMA | 左电机速度 PWM，TIM2_CH1 |
| PA1 | PWMB | 右电机速度 PWM，TIM2_CH2 |
| PA4 | AIN1 | 左电机方向 |
| PA5 | AIN2 | 左电机方向 |
| PB8 | BIN1 | 右电机方向 |
| PB9 | BIN2 | 右电机方向 |
| PB10 | STBY | 电机使能 |

控制逻辑：
```
AIN1=1 AIN2=0 → 左正转    AIN1=0 AIN2=1 → 左反转
BIN1=1 BIN2=0 → 右正转    BIN1=0 BIN2=1 → 右反转
AIN1=0 AIN2=0 → 左刹车    BIN1=0 BIN2=0 → 右刹车
STBY=1 → 使能             STBY=0 → 禁用
```

### 云台舵机（4线）

| C8T6 | 舵机 | 说明 |
|------|------|------|
| PA6 | MG90S ① 信号（白/橙） | 水平轴，TIM3_CH1, 50Hz PWM |
| PA7 | MG90S ② 信号（白/橙） | 俯仰轴，TIM3_CH2, 50Hz PWM |
| — | 舵机 VCC（红） | → MP1584② 5V |
| — | 舵机 GND（棕/黑） | → GND |

PWM 参数：周期 20ms，脉宽 0.5~2.5ms 对应 0°~180°

### 激光模组（2线）

| C8T6 | 激光 | 说明 |
|------|------|------|
| PB0 | SIG（信号） | 高电平=激光开 |
| — | VCC（红） | → MP1584② 5V |
| — | GND（黑） | → GND |

### MaixCam → 串口（4线）

| C8T6 | MaixCam | 说明 |
|------|---------|------|
| PA9 | RX | C8T6 TX → MaixCam RX |
| PA10 | TX | C8T6 RX ← MaixCam TX |
| — | VCC | → MP1584② 5V |
| — | GND | → GND |

UART 115200bps 8N1

### TCRT5000 5路循迹（7线）

| C8T6 | TCRT5000 | 说明 |
|------|----------|------|
| PB3 | OUT1 | 最左探头，黑线上=0（需释放JTAG） |
| PB4 | OUT2 | 左探头（需释放JTAG） |
| PB5 | OUT3 | 中探头 |
| PB12 | OUT4 | 右探头 |
| PB13 | OUT5 | 最右探头 |
| — | VCC | → MP1584① 5V |
| — | GND | → GND |

输出：TTL 数字量，黑线低电平(0)、白底高电平(1)

> **注意**：PB3/PB4 上电默认为 JTAG 引脚，必须在初始化时释放：
> ```c
> RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);
> GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);
> ```
> 释放后 PA13/PA14 的 SWD 仍可用，不影响下载调试。

> **注意**：PB3/PB4 上电默认为 JTAG 引脚，必须在初始化时释放：
> ```c
> RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);
> GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);
> ```
> 释放后 PA13/PA14 的 SWD 仍可用，不影响下载调试。
