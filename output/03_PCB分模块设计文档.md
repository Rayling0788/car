## MOD-1 电源管理模块

### 供电架构

```
7.4V 锂电池
  │  红(+) ─┬─ J1 脚1(BAT+) 
  │  黑(-) ─┴─ J1 脚2(BAT-)
  │
  ├─ J1 脚1 → SW1(COM1) → SW1(NO1) → F1(IN) → F1(OUT) = VBAT_FUSED
  │                                                │
  │    ┌───────────────────────────────────────────┤
  │    │                  │                        │
  │  U2 MP1584①        U3 MP1584②              U4 MP1584③
  │  主控路 5V         瞄准路 5V                电机路 5V
  │  OUT+               OUT+                     OUT+
  │    │                  │                        │
  │  SW2(COM1)         SW3(COM1)                 直通 无开关
  │  SW2(NO1)          SW3(NO1)
  │    │                  │                        │
  │  VCC_MCU           VCC_AIM                  VCC_MOT
  │    │                  │                        │
  │  ├─ C8T6 5V脚      ├─ J4 舵机①VCC          ├─ U5 TB6612 VM
  │  ├─ J7 循迹 VCC    ├─ J5 舵机②VCC          ├─ U5 TB6612 VCC
  │  └─ J8 OLED VCC    ├─ J9 激光 VCC           └─ C5 去耦
  │                     └─ C4/C7 去耦
  │
  J1 脚2 ────────────────── GND（全板共地）
```

### 三路电源说明

| 路名 | 降压模块 | 开关 | LED | 输出电压 | 负载 | 设计电流 |
|------|---------|------|-----|----------|------|----------|
| **主控路** | U2 MP1584 | SW2 | D2 红 | 5V | C8T6、循迹、OLED | ≈0.5A |
| **瞄准路** | U3 MP1584 | SW3 | D3 红 | 5V | 舵机×2、激光 | ≈1.5A |
| **电机路** | U4 MP1584 | 无，软件控 STBY | 无 | 5V | TB6612 VM+VCC | ≈2A |

**三路独立原因：**
- 比赛基本要求(1)：巡线时瞄准路必须可断电，主控路继续工作
- 电机启停噪声不串扰 MCU/传感器
- 单路 MP1584 3A 扛不住全部负载峰值

### 各元件引脚连接

#### J1 — 电池输入端子（KF301-2P / 5.08mm 间距）

| 脚号 | 丝印标注 | 接线 | 线宽要求 |
|------|----------|------|----------|
| 1（圆圈标记端） | BAT+ | → SW1 的 COM1 | ≥2mm |
| 2 | BAT- | → GND | 就近地过孔 |

#### SW1/SW2/SW3 — 总开关及各路开关（SS-12F44，5脚 DPDT）

> 每个 SS-12F44 是双刀双掷开关，内部有两组。我们只用一组。

| 脚位 | 名称 | SW1（总开关）| SW2（主控路）| SW3（瞄准路）|
|------|------|-------------|-------------|-------------|
| COM1 | 公共端1 | J1 脚1 BAT+ | U2 OUT+ | U3 OUT+ |
| NO1 | 常开端1 | → F1 IN | → VCC_MCU + D2 | → VCC_AIM + D3 |
| NC1 | 常闭端1 | 悬空（红×） | 悬空（红×） | 悬空（红×） |
| COM2 | 公共端2 | 悬空（红×） | 悬空（红×） | 悬空（红×） |
| NO2/NC2 | 第二组 | 悬空（红×） | 悬空（红×） | 悬空（红×） |

> 未用的 3 个脚在原理图中放「非连接标识（红×）」，DRC 不会报警。

#### F1 — 自恢复保险丝（PTC 2A，脚距 5mm）

| 脚 | 接线 |
|----|------|
| IN | SW1 的 NO1 |
| OUT | VBAT_FUSED（分三路到 U2/U3/U4 的 IN+） |

> 型号：JK250-020U，搜 `jk250 020u`

#### U2 / U3 / U4 — MP1584 降压模块（×3）

> 每个 MP1584 模块有 8 个孔：IN+×2、IN-×2、OUT+×2、OUT-×2。同标注的两孔内部连通，任选一孔焊接即可。

| 模块 | IN+ 接 | IN- 接 | OUT+ 接 | OUT- 接 |
|------|--------|--------|---------|---------|
| U2 主控路 | VBAT_FUSED | GND | → SW2 COM1 | GND |
| U3 瞄准路 | VBAT_FUSED | GND | → SW3 COM1 | GND |
| U4 电机路 | VBAT_FUSED | GND | → VCC_MOT | GND |

> 出厂预调为 5V，不需调电位器。三块模块方向一致，丝印标 IN/OUT。

#### D1/D2/D3 — 电源指示灯

| 编号 | 颜色 | 位置 | 接法 |
|------|------|------|------|
| D1 | 绿 | VBAT_FUSED | VBAT_FUSED → R1(1kΩ 1/4W 直插) → LED长脚 → LED短脚 → GND |
| D2 | 红 | VCC_MCU | VCC_MCU → R2(1kΩ 1/4W 直插) → LED长脚 → LED短脚 → GND |
| D3 | 红 | VCC_AIM | VCC_AIM → R3(1kΩ 1/4W 直插) → LED长脚 → LED短脚 → GND |

#### 滤波与去耦电容

> C2 已删除。因为三路 5V 独立供电没有统一 5V 总线，且每路已有 0.1μF 去耦，MP1584 模块板载输出电容已够用。

| 编号 | 值 | 封装 | 位置 | 接法 |
|------|-----|------|------|------|
| C1 | 100μF/25V | 电解 直插 Φ6.3 | J1 输入端旁 | BAT+ ↔ GND |
| C3 | 0.1μF | 独石 直插 脚距2.54mm | C8T6 5V脚旁 | VCC_MCU ↔ GND |
| C4 | 0.1μF | 独石 直插 脚距2.54mm | J4/J5 VCC 旁 | VCC_AIM ↔ GND |
| C5 | 0.1μF | 独石 直插 脚距2.54mm | TB6612 VCC 旁 | VCC_MOT ↔ GND |
| C6 | 0.1μF | 独石 直插 脚距2.54mm | J7 VCC 旁 | VCC_MCU ↔ GND |
| C7 | 0.1μF | 独石 直插 脚距2.54mm | J9 VCC 旁 | VCC_AIM ↔ GND |

## MOD-2 主控模块

> 器件：STM32F103C8T6 Blue Pill 最小系统板，40 脚符号
> 实际烧录用 Blue Pill 板上自带 SWD 排针，**不需要底板 SWD 接口**

### STM32 40 脚符号引脚分配

```
符号脚位 → 实际 STM32 引脚 → 本板用途
──────────────────────────────────────
脚1   PB12  → J7 循迹 OUT4（右）
脚2   PB13  → J7 循迹 OUT5（最右）
脚3   PB14  → 红× 未用
脚4   PB15  → 红× 未用
脚5   PA8   → 红× 未用
脚6   PA9   → J6 MaixCam 脚4 RX
脚7   PA10  → J6 MaixCam 脚3 TX
脚8   PA11  → 红× 未用
脚9   PA12  → 红× 未用
脚10  PA15  → 红× 未用
脚11  PB3   → J7 循迹 OUT1（最左）⚠️ 需释放 JTAG
脚12  PB4   → J7 循迹 OUT2（左）⚠️ 需释放 JTAG
脚13  PB5   → J7 循迹 OUT3（中）
脚14  PB6   → J8 OLED SCL
脚15  PB7   → J8 OLED SDA
脚16  PB8   → U5 TB6612 BIN1
脚17  PB9   → U5 TB6612 BIN2
脚18  5V    → VCC_MCU（U2 经 SW2 的 5V 输出）
脚19  GND   → GND
脚20  VCC3V3 → 红×（板载 LDO 输出，不接）
脚21  VBAT  → 红×（无外部 RTC 电池）
脚22  PC13  → 红×（板载 LED，Blue Pill 自带）
脚23  PC14  → 红× 未用
脚24  PC15  → 红× 未用
脚25  PA0   → U5 TB6612 PWMA（左电机 PWM）
脚26  PA1   → U5 TB6612 PWMB（右电机 PWM）
脚27  PA2   → 红× 未用
脚28  PA3   → 红× 未用
脚29  PA4   → U5 TB6612 AIN1（左电机方向）
脚30  PA5   → U5 TB6612 AIN2（左电机方向）
脚31  PA6   → J4 舵机① SIG（水平轴）
脚32  PA7   → J5 舵机② SIG（俯仰轴）
脚33  PB0   → R4(1kΩ) → Q1 栅极（激光控制）
脚34  PB1   → 红× 未用
脚35  PB10  → U5 TB6612 STBY（电机使能）
脚36  PB11  → 红× 未用
脚37  NRST  → 红×（板载复位电路）
脚38  VCC3V3 → 红×（板载 LDO 输出，不接）
脚39  GND   → GND
脚40  GND   → GND
```

### 关键注意事项

- **脚18（5V）** 接下板 5V 供电，Blue Pill 板载 AMS1117 自行降压到 3.3V
- **脚20/38（VCC3V3）** 是板载 LDO 输出端，不需要外接电源，置红×
- **PA13、PA14**（SWD）不在 40 脚符号中，位于 Blue Pill 板上独立 SWD 排针孔
- 烧录时 ST-Link 直接插 Blue Pill 的 SWD 孔，不经过底板

## MOD-3 电机驱动模块

> 器件：TB6612FNG 模块（U5），驱动 2 路 TT 减速电机
> 电源：VM、VCC 均接 VCC_MOT（U4 输出 5V）

### 控制信号连接

| STM32 脚 | TB6612 脚 | 线网名 | 功能说明 |
|----------|-----------|--------|----------|
| PA0 | PWMA | PWM_LEFT | 左电机 PWM 速度（TIM2_CH1，频率 10kHz） |
| PA1 | PWMB | PWM_RIGHT | 右电机 PWM 速度（TIM2_CH2，频率 10kHz） |
| PA4 | AIN1 | DIR_L1 | 左电机方向位 1 |
| PA5 | AIN2 | DIR_L2 | 左电机方向位 2 |
| PB8 | BIN1 | DIR_R1 | 右电机方向位 1 |
| PB9 | BIN2 | DIR_R2 | 右电机方向位 2 |
| PB10 | STBY | MOT_EN | 使能：高=工作，低=休眠 |

### 供电连接

| TB6612 脚 | 接 | 说明 |
|-----------|----|------|
| VM | VCC_MOT（5V） | 电机功率电源，C5 去耦 |
| VCC | VCC_MOT（5V） | 芯片逻辑电源，VM/VCC 并一起 |
| GND | GND | 所有 GND 脚接地 |

### 电机输出

| TB6612 输出 | → | 端子 | 丝印 |
|------------|---|------|------|
| AO1 | → | J2 脚1 | MOT_L+ |
| AO2 | → | J2 脚2 | MOT_L- |
| BO1 | → | J3 脚1 | MOT_R+ |
| BO2 | → | J3 脚2 | MOT_R- |

#### J2 — 左电机端子（KF301-2P 5.08mm）

| 脚号 | 丝印 | 接 |
|------|------|----|
| 1（圆圈） | MOT_L+ | TB6612 AO1 |
| 2 | MOT_L- | TB6612 AO2 |

#### J3 — 右电机端子（KF301-2P 5.08mm）

| 脚号 | 丝印 | 接 |
|------|------|----|
| 1（圆圈） | MOT_R+ | TB6612 BO1 |
| 2 | MOT_R- | TB6612 BO2 |

### 控制真值表

| STBY | AIN1 | AIN2 | 左电机 | BIN1 | BIN2 | 右电机 |
|------|------|------|--------|------|------|--------|
| 1 | 1 | 0 | 正转 | 1 | 0 | 正转 |
| 1 | 0 | 1 | 反转 | 0 | 1 | 反转 |
| 1 | 0 | 0 | 刹车 | 0 | 0 | 刹车 |
| 1 | 1 | 1 | 刹车 | 1 | 1 | 刹车 |
| 0 | × | × | 休眠 | × | × | 休眠 |

> 代码初始化时 PB10 默认拉低（STBY=0），防止上电瞬间电机乱转。

## MOD-5 激光模组模块

> 器件：5mW 红色激光头（2线制：红 VCC、黑 GND）
> 因激光模组无信号线，用 NMOS 作电子开关控制 GND 回路通断

### 电路原理

```
VCC_AIM 5V ─── J9 脚1 ─── 激光红线 ─── [激光头] ─── 激光黑线 ─── J9 脚2
                                                                    │
                                                               Q1 D（漏极）
                                                                  │  ← PB0 高→导通
                                                               Q1 S（源极）
                                                                  │
                                                                 GND

PB0 ─── R4(1kΩ) ───┬─── Q1 G（栅极）
                    │
                    R5(10kΩ)
                    │
                   GND
```

### 元件清单

| 编号 | 元件 | 型号 | 封装 | 搜什么 |
|------|------|------|------|--------|
| Q1 | N-MOS 管 | 2N7000 | TO-92 直插 | `2N7000` |
| R4 | 栅极串联电阻 | 1kΩ | 直插 1/4W | `1k 1/4W 直插` |
| R5 | 栅极下拉电阻 | 10kΩ | 直插 1/4W | `10k 1/4W 直插` |

### TO-92 引脚位（面朝自己，脚向下）

| 引脚 | 位置 | 接 |
|------|------|----|
| S（源极） | 左 | GND |
| G（栅极） | 中 | R4 → PB0，同时 R5 → GND |
| D（漏极） | 右 | J9 脚2（激光黑线侧） |

### J9 — 激光接口（1×2P 排针 2.54mm）

| 脚号 | 丝印 | 接 | 激光线色 |
|------|------|----|----------|
| 1（圆圈） | VCC | VCC_AIM（5V，U3 经 SW3） | 红 |
| 2 | GND | Q1 D（漏极） | 黑 |

### 控制逻辑

| PB0 | NMOS | 激光 |
|-----|------|------|
| 高（3.3V） | 导通 D-S | 亮 |
| 低（0V） | 关断 | 灭 |

> R5 10kΩ 下拉保证 MCU 上电初始化前栅极为低，激光默认不亮。
> R4 1kΩ 限制 GPIO 对栅极电容的充放电电流，保护 PB0。

## MOD-6 视觉通信模块

> 器件：MaixCAM Pro（带电池版）
> 接口：UART1 串口 115200 8N1
> MaixCAM Pro GPIO 排针引脚参考自 `MaixCAM-Pro IO Pic_v1.2`

### MaixCAM Pro GPIO 排针（底板侧接线参考）

> MaixCAM Pro 底部排针分左右两列，我们用到左侧列的 UART1 引脚：

| 排针位置 | MaixCAM Pro 信号 | 功能 | 接底板 J6 脚位 |
|----------|-----------------|------|----------------|
| 左侧 Pin1 | A29 / UART2_RX / JTAG_TDO | 不用 | — |
| 左侧 Pin2 | **A19 / UART1_TX** / PWM7 / JTAG_TMS | MaixCam 发送 | → J6 脚3 |
| 左侧 Pin3 | A28 / UART2_TX / JTAG_TDI | 不用 | — |
| 左侧 Pin4 | **A18 / UART1_RX** / PWM6 / JTAG_TCK | MaixCam 接收 | → J6 脚2 |
| 左侧 Pin5 | VSYS | 系统供电（4~5.5V） | 不接（带电池版自供电） |
| 左侧 Pin6 | **GND** | 共地 | → J6 脚1 |
| 左侧 Pin7 | SERVOS | 不用 | — |

### J6 — MaixCam 接口（1×3P 排针 2.54mm）

> 带电池版3线通信。圆圈=脚1 在最上方。

| 脚号 | 丝印 | 接 MaixCAM Pro | 接 STM32 | 信号方向 |
|------|------|---------------|----------|----------|
| 1（圆圈，上） | GND | 左侧 Pin6 GND | GND | 共地 |
| 2（中） | RX | 左侧 Pin4 A18（UART1_RX） | **PA9**（USART1_TX） | C8T6→MaixCam |
| 3（下） | TX | 左侧 Pin2 A19（UART1_TX） | **PA10**（USART1_RX） | MaixCam→C8T6 |

### 通信参数

| 参数 | 值 |
|------|----|
| 接口 | USART1（PA9 TX，PA10 RX） |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验 | 无 |
| 停止位 | 1 |

### Maixcam 避坑提示

1. MaixCam 的 **TX(A19) → C8T6 RX（PA10）**，**C8T6 TX（PA9）→ MaixCam RX(A18)**，交叉连接
2. 用 **UART1**（A19/A18），不用 UART0（A16/A17），UART0 是系统日志串口
3. MaixPy 代码中 UART1 设备路径为 `/dev/ttyS1`：`UART("/dev/ttyS1", 115200)`
4. 如果误用 UART0，代码里必须跳过启动日志，读到 `serial ready` 后才开始解析

## MOD-7 循迹传感器模块

### J7 — 循迹接口（1×7P 排针 2.54mm）

| 脚号 | 丝印 | 接 | 说明 |
|------|------|----|------|
| 1（圆圈） | VCC | VCC_MCU（5V，U2 经 SW2） | 传感器供电 |
| 2 | GND | GND | 共地 |
| 3 | OUT1 | **PB3** | 最左探头 ⚠️ JTAG 释放 |
| 4 | OUT2 | **PB4** | 左探头 ⚠️ JTAG 释放 |
| 5 | OUT3 | **PB5** | 中探头 |
| 6 | OUT4 | **PB12** | 右探头 |
| 7 | OUT5 | **PB13** | 最右探头 |

### 循迹逻辑

| 输出电平 | 含义 |
|----------|------|
| 0（低） | 探到黑线 |
| 1（高） | 白底 |

### ⚠️ PB3/PB4 必须释放 JTAG

PB3、PB4 上电默认为 JTDO、JTRST 功能，**代码初始化时必须释放**：

```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);
GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);
```

释放后 PA13/PA14 的 SWD 仍可用，不影响烧录调试。
