## 信号流

```
靶面（白底黑同心圆）
    │
    ↓ 光学
┌──────────┐
│ MaixCam   │  识别同心圆 → 计算靶心像素偏移 (Δx, Δy)
└────┬─────┘
     │ UART @115200
     ↓
┌──────────┐
│ C8T6      │  像素偏移 → 舵机角度映射 → PWM
└────┬─────┘
     │
     ├──→ 舵机 PWM (PA6/PA7) → 云台跟踪靶心
     ├──→ 激光 GPIO (PB0) → 光斑落靶
     ├──→ TB6612 PWM (PA0/PA1) → 差速电机
     └──← 循迹 GPIO (PB3-5, PB12-13) ← 红外5路
```

## 开发顺序

### 第1步：MaixCam 独立调试
- 刷固件、安装开发环境
- 拍靶面照片 → 灰度化 → 找同心圆（Hough 圆检测） → 算出靶心坐标
- 通过串口输出 "靶心x,靶心y,半径" 格式数据
- **验证**：PC 串口助手看坐标，移动靶面看坐标是否跟动

### 第2步：C8T6 基础驱动
- GPIO、定时器、PWM、UART1、I2C1 初始化
- 串口接收 MaixCam 坐标 → OLED 显示
- 舵机 PWM 50Hz 波形验证
- **验证**：OLED 显示收到的坐标值，示波器看 PA6/PA7 有 50Hz 波形

### 第3步：静态打靶
- 云台 + MaixCam 装好
- 摄像头画面中心对准靶心 → 记录"零点"舵机角度
- 画面中靶心偏移量 → 映射到舵机角度修正量（P控制即可）
- 偏差小于阈值 → 触发激光
- **验证**：车静止，放靶面前 50cm，看光斑是否落在 2cm 圆内

### 第4步：小车巡线
- 5路循迹数据读取
- 偏差计算 + PID 控制左右轮差速
- 沿黑线行驶一圈
- **验证**：N=1 圈，≤20s，不脱线

### 第5步：整机联动
- 巡线 + 瞄准模块同时工作
- 行驶中接收坐标 → 舵机修正 → 打靶
- 调优：PID 参数、舵机响应速度、激光触发时机
- **验证**：N=1 圈，D1≤2cm

### 第6步（发挥）：抗干扰
- 靶面贴 6cm 黑色实心圆
- MaixCam 区分"同心圆"和"实体黑圆"
- 激光避开黑块打靶
